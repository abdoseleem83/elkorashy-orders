🔍 فحص سيرفر القرشي

الأداة دي بتقولك رابط الـ Apps Script بتاعك شغّال ولا لأ، وعلى أنهي نسخة — من غير ما تخمّن.
تجيبه من: محرر Apps Script ← نشر ← إدارة عمليات النشر ← انسخ «رابط تطبيق الويب»
إيه اللي بتفحصه الأداة؟
  1. الرابط موجود أصلاً؟ — لو ٤٠٤، يبقى النشر اتشال أو اتعمل رابط جديد.
  2. النسخة كام؟ — لازم تطابق نسخة التطبيق، وإلا هتحصل أعطال غامضة.
  3. الأسرار متظبطة؟ — بتقولك متسجّلة ولا لأ (من غير ما تطبع أي قيمة).
