# القرشي — طلبات الموزعين

نظام طلبات لأبواب وشبابيك الـ UPVC. تطبيق ويب PWA بصفحة واحدة، من غير build ولا npm ولا framework.

🔗 **التطبيق:** https://abdoseleem83.github.io/elkorashy-orders/

---

## المعمارية

```
المتصفح (index.html)  →  fetch  →  Google Apps Script /exec  →  Google Sheets
                                          ↓
                                   CallMeBot (واتساب)
```

مفيش سيرفر ولا داتابيز — Google Sheets هي قاعدة البيانات، و Apps Script هو الـ API.

| الملف | الوصف |
|---|---|
| `index.html` | التطبيق كله: HTML + CSS + JS |
| `apps_script.gs` | الباك إند — **نسخة مرجعية**، النشر الحقيقي في محرر Apps Script |
| `sw.js` | Service Worker (كاش أوفلاين) |
| `manifest.json` | إعدادات الـ PWA |
| `logo.jpg` | اللوجو |
| `data/catalog-fallback.json` | أسامي الأصناف — آخر خيار لو مفيش نت ولا نسخة محفوظة |
| `vendor/` | المكتبات (html2canvas · jspdf · exceljs) — محلية، مش من CDN |
| `tests/` | اختبارات تشغيل حقيقية بالمتصفح |

## ⚠️ قاعدة أساسية: مفيش أي سر في المستودع ده

**المستودع عام.** أي رقم سري أو مفتاح API بتكتبه في أي ملف هنا بيبقى مكشوف للكل — وبيفضل مكشوف في تاريخ الـ git حتى لو مسحته بعدين.

كل الأسرار بتتخزّن في **Script Properties** بتاع Apps Script:

| المفتاح | الوصف |
|---|---|
| `ADMIN_PIN` | رقم فتح "متابعة المخزن" |
| `MANAGE_PIN` | رقم فتح تبويب "الإدارة" |
| `CALLMEBOT_APIKEY` | مفتاح CallMeBot المرتبط برقم واتساب الأدمن |
| `ADMIN_WHATSAPP` | رقم واتساب الأدمن (صيغة دولية `+20...`) |
| `TOKEN_SECRET` | بيتولّد تلقائيًا — مفتاح توقيع التوكنات |

### إعداد أول مرة

١. افتح محرر Apps Script (خاص، مش عام)
٢. افتح `setupWizard()`، اكتب القيم جوه الأقواس، اضغط **Run**
٣. **امسح القيم وسيبها فاضية واحفظ** — عشان لو الملف اتنسخ هنا مايبقاش فيه سر
٤. شغّل `setup()` مرة واحدة (بتجهّز الشيتات — آمنة، مابتمسحش أي بيانات)
٥. شغّل `installTriggers()` مرة واحدة (طابور الواتساب + مزامنة المحجوز)

عايز تغيّر رقم واحد بس بعدين؟ شغّل `setupWizard()` تاني وسيب باقي الخانات فاضية.

### لو شكيت إن حد وصل لتوكن

شغّل `revokeAllTokens()` — بيلغي كل التوكنات فورًا (أدمن + إدارة + كل الموزعين).

## النشر

### الواجهة (index.html وباقي الملفات)

ارفع الملفات على الفرع الرئيسي — GitHub Pages بينشر تلقائيًا.

### الباك إند (apps_script.gs)

الملف هنا **نسخة مرجعية بس** ومش بينتشر لوحده. الخطوات:

١. الصق الملف كله في محرر Apps Script
٢. **Deploy → Manage deployments → عدّل النشر الحالي → Version: New version**
٣. افتح `‎<رابط exec>?action=version` وتأكد إن الرقم الراجع = `APP_VERSION`

> ⚠️ لو نسيت الخطوة التالتة، ممكن تفضل شغّال بنسخة قديمة من غير ما تاخد بالك. ده حصل قبل كده: زرار "رفع الأصناف" فضل بيفشل بصمت شهور لأن السيرفر مكانش عارف الـ action أصلاً.

### 🔑 رقم النسخة في ٣ أماكن — لازم يتغيروا مع بعض

| الملف | المتغير |
|---|---|
| `index.html` | `APP_BUILD` |
| `sw.js` | `CACHE_VERSION` |
| `apps_script.gs` | `APP_VERSION` |

نسيان واحد فيهم = المستخدمين يفضلوا على نسخة قديمة، أو التشخيص يدّي معلومة غلط.

## الاختبارات

اختبارات حقيقية بتشغّل التطبيق في متصفح فعلي وبتتحقق من كل المسارات المهمة
(دخول، تصفح الأصناف، إضافة للسلة، إرسال طلب، المودالات، شاشة الأدمن، الأرشيف).

```bash
npx http-server -p 8099 -s .      # في تيرمينال
node tests/flow.mjs               # مسار الموزّع
node tests/admin.mjs              # مسار الأدمن والأرشيف
```

محتاج `playwright` متسطّب. لو متسطّب عام مش محلي:

```bash
export PLAYWRIGHT_MODULE=/path/to/node_modules/playwright/index.mjs
export CHROME_PATH=/path/to/chrome     # اختياري
```

نداءات Apps Script كلها متبدّلة بردود وهمية جوه الاختبار، فهو مابيلمسش
بياناتك الحقيقية خالص.

## الأمان — إيه اللي متعمول

| الحماية | الحالة |
|---|---|
| الأسرار بره الكود | ✅ Script Properties |
| كلمات المرور | ✅ SHA-256 + salt لكل مستخدم (ترقية تلقائية للحسابات القديمة) |
| حد لمحاولات الدخول | ✅ ٥ محاولات → قفل ١٥ دقيقة |
| "طلباتي" | ✅ توكن جلسة — الموزّع يشوف طلباته هو بس |
| عمليات الأدمن | ✅ توكن موقّع بـ HMAC، صالح ١٢ ساعة |
| العمليات المدمِّرة | ✅ POST بس، مش روابط GET |
| حماية XSS | ✅ كل نص من المستخدم بيعدّي على `esc()` |
| مكتبات الطرف التالت | ✅ محلية في `vendor/` — مفيش CDN |

### ملاحظات معروفة

- **إشعارات المتصفح (Web Push) متوقفة.** Apps Script مافيهوش ECDSA ولا AES-GCM ولا ECDH، فتنفيذ بروتوكول Web Push صح (VAPID JWT + تشفير aes128gcm) مش ممكن منه. التبليغ كله على واتساب. عايز تشغّلها؟ محتاج خدمة وسيطة زي Firebase Cloud Messaging HTTP v1 أو OneSignal — الاتنين بيتنادوا بـ `UrlFetchApp` عادي.
- **الرصيد رقم عام واحد لكل المخازن**، والحجز بيتطبق على **طنطا بس** (`RESERVED_WAREHOUSE_`). لو عايز رصيد منفصل لكل مخزن، محتاج أعمدة منفصلة في شيت الأصناف.

## شيتات جوجل

| الشيت | الغرض |
|---|---|
| `Orders` | الطلبات (١٢ عمود — آخر واحد اسم المستخدم) |

## دوال الصيانة (من محرر Apps Script)

| الدالة | الغرض |
|---|---|
| `setupWizard()` | ضبط الأسرار |
| `setup()` | تجهيز الشيتات (آمنة — مابتمسحش) |
| `installTriggers()` | تركيب المهام الدورية |
| `recalculateReservedNow()` | إعادة حساب المحجوز فورًا |
| `hashAllPasswords()` | تشفير كل الباسوردات القديمة دفعة واحدة |
| `revokeAllTokens()` | إلغاء كل الجلسات |

## مصطلحات

- **حالات الطلب:** `تم استلام الطلب` → `تم تنفيذ الطلب`. و`مُعدّل` للنسخة القديمة من طلب اتعدّل.
- **التعديل** بيعمل صف **جديد** برقم جديد، والقديم بيتعلّم `مُعدّل` (مش بيحدّث نفس الصف).
- **الوحدات:** لفة/كرتونة = وحدة كبيرة، بتتحوّل للصغيرة (عود/قطعة) بالضرب في محتوى اللفة (عمود D).
- **نوع الحساب:** `موزع` أو `عميل`. العميل مابيتسألش عن المخزن ومابيشوفش حالة الرصيد.
